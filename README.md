## 📲 Hướng dẫn cài đặt trên iPhone (Shadowrocket)

1. Mở **Shadowrocket** → tab **Cấu hình** (Configuration) → bấm dấu **+** ở góc trên bên phải.
2. Dán link module:
   ```text
   https://raw.githubusercontent.com/DoKhacQuyen94/locket-mod/main/locket-dokhacquyen.sgmodule
   ```
3. Nhấn vào module vừa thêm → Bật **MITM**.
4. Cài đặt chứng chỉ CA của Shadowrocket (nếu chưa cài):
   - Vào Shadowrocket → **Cấu hình** → **Chứng chỉ tin cậy** → *Generate/Install*.
   - Mở Safari tải profile → **Cài đặt** iPhone → **Cài đặt chung** → **VPN & Quản lý thiết bị** → cài đặt hồ sơ.
   - **Cài đặt chung** → **Giới thiệu** → **Cài đặt tin cậy chứng chỉ** (ở dưới cùng) → gạt **Bật** cho chứng chỉ của Shadowrocket.
5. Bật VPN Shadowrocket, đóng ứng dụng Locket và mở lại để sử dụng.
