# Locket Gold - DoKhacQuyen

Module Shadowrocket mở khóa Locket Gold cá nhân hóa bởi **DoKhacQuyen94**.

## Hướng dẫn cài đặt trên iPhone (Shadowrocket)

1. Mở **Shadowrocket** → tab **Cấu hình** (Configuration) → bấm dấu **+** ở góc trên.
2. Dán link module:
   ```text
   https://raw.githubusercontent.com/DoKhacQuyen94/locket-mod/main/locket-dokhacquyen.sgmodule
   ```
3. Nhấn vào module vừa thêm → Bật **MITM**.
4. Cài đặt chứng chỉ CA của Shadowrocket:
   - Vào Shadowrocket → **Cấu hình** → **Chứng chỉ tin cậy** → *Generate/Install*.
   - Mở Safari cho phép tải hồ sơ cấu hình.
   - Vào **Cài đặt** iPhone → **Cài đặt chung** → **VPN & Quản lý thiết bị** → Chọn cấu hình Shadowrocket → **Cài đặt**.
   - Vào **Cài đặt chung** → **Giới thiệu** → **Cài đặt tin cậy chứng chỉ** (ở dưới cùng) → Gạt **Bật** cho chứng chỉ của Shadowrocket.
5. Bật VPN Shadowrocket, đóng ứng dụng Locket và mở lại để sử dụng.
